## 🔴 CRITICAL (7)

**C1. Mất buổi tập offline khi có mạng trở lại** — `features/workout/presentation/providers/workout_providers.dart:22-35`
`build()`/`refresh()` fetch remote thành công → `replaceLocalCache` → `clearAllForUser()` xóa TOÀN BỘ cache local (kể cả row `isSynced=false`) rồi hydrate từ remote. `syncPendingData()` tồn tại nhưng **0 nơi gọi**. Impact: tập ở hầm xe/máy bay → mở app lúc có mạng → mất vĩnh viễn buổi tập.
*Fix gợi ý: gọi `syncPendingData()` trước `replaceLocalCache`.*

**C2. Remote rỗng làm buổi tập local "biến mất"** — `workout_providers.dart:35,57`
`return remoteSessions` kể cả khi remote `[]`; nhánh fallback local chỉ chạy khi remote throw. Impact: buổi tập offline biến mất khỏi UI ngay khi có mạng.

**C3. Kẹt màn hình sau khi lưu profile lần đầu** — `features/profile/presentation/screens/profile_setup_screen.dart:155`
`_saveProfile` chỉ `pop()` khi `canPop()` true, nhưng onboarding đi bằng `pushReplacement` → route duy nhất → không điều hướng đi đâu. Impact: user mới thấy toast "thành công" rồi kẹt cứng, phải kill app.

**C4. Timeout 4s biến thành "chưa có profile", đẩy user oan vào tạo lại profile** — `features/profile/presentation/providers/user_profile_providers.dart:48-53`
`.timeout(4s, onTimeout: () => false)` + repository catch mọi lỗi remote → `return false`. Màn hình lỗi + nút retry ở auth_wrapper **không bao giờ hiện** vì không có exception nào được ném. Impact: mạng chập chờn > 4s → user đang dùng bị bắt tạo lại profile.

**C5. Register pass 6 ký tự xong bị bắt đổi ngay** — `features/auth/presentation/screens/register_screen.dart:272`
Form chỉ yêu cầu 6 ký tự, nhưng `auth_wrapper.dart:104-108` bắt mọi user qua `ForcePasswordUpgradeScreen` (strict: 8 ký tự + hoa/thường/số/đặc biệt). Impact: gãy onboarding ngay lần đầu vào app.

**C6. Công tắc master "Cho phép thông báo" bị bỏ qua** — `app/app.dart:196`
`_refreshNotificationSchedules()` truyền nhầm `workoutRemindersEnabled` thay vì master pref `kNotificationsPrefKey`. Impact: user TẮT toàn bộ thông báo vẫn bị schedule lại và nhận noti.

**C7. Steps đi lúc pause bị cộng dồn vào quãng đường khi resume** — `features/workout/presentation/screens/record/record_providers.dart:519-536`
`pauseWorkout()` pause broadcast stream (event bị drop) nhưng service vẫn đếm; `resume()` nhận `sessionSteps` đã gồm steps lúc pause → `delta = sessionSteps - state.stepCount` cộng "ma" vào distance + calories. Impact: nghỉ giữa buổi đi lại vài chục bước → quãng đường/calo tăng ảo.

## 🟠 HIGH (16)

**H1. Nút Skip chết trong lúc "ĐANG KHÓA TÍN HIỆU GPS"** — `record_screen.dart:195` + `workout_3d_countdown_overlay.dart:101,136`
Tap skip vẫn `await` đúng `_startupGpsLockFuture` cũ (timeout 15s). Impact: user chờ 15s tưởng app treo.

**H2. `stopWorkout()` throw khi mất user → kẹt + mất dữ liệu** — `record_providers.dart:566`
`throw` trong try/finally không catch; status đã `stopping`, sensor đã shutdown, không UI retry; back → provider autoDispose → buổi tập trong RAM mất trắng.

**H3. `saveSessionRemote` không timeout → kẹt "Saving workout..."** — `record_providers.dart:592`
Supabase client không timeout mặc định; `cacheSessionLocal` nằm SAU await → back ra là mất buổi tập.

**H4. Không có crash-recovery cho buổi tập đang ghi** — toàn bộ `features/workout/**`
Session state chỉ trong RAM (autoDispose); chỉ `stopWorkout()` mới cache local. Impact: OS kill/hết pin giữa buổi chạy dài → mất toàn bộ.

**H5. Nút "GỬI LẠI EMAIL" gây crash** — `forgot_password_screen.dart:66`
`_formKey.currentState!.validate()` nhưng ở state success Form đã bị AnimatedSwitcher gỡ → null → crash đúng lúc user cần resend.

**H6. Tài khoản username không có đường khôi phục mật khẩu** — `features/auth/presentation/helpers/username_auth.dart:14-16`
Email giả `username@aetron.local`, Supabase không gửi mail tới `.local`. Impact: quên pass = mất tài khoản vĩnh viễn.

**H7. Imperial: preset goal km bị hiểu thành miles** — `goal_screen.dart:40,494,507,816`
Preset trả số km gán vào `_targetValue` (đang hiện miles), lúc lưu chia 0.621371 → "20" thành ~32.2 km, sai 1.6 lần âm thầm.

**H8. Goal cự ly bỏ qua mọi buổi tập không GPS** — `goal_providers.dart:133` *(2 nhóm cùng phát hiện)*
Chỉ cộng `validDistanceKm`, không fallback `distanceKm` → chạy treadmill cả tuần goal vẫn 0% trong khi achievements hiện đúng.

**H9. Đổi tên hiển thị xong vẫn hiện tên cũ** — `profile_screen.dart:141`
Không await sheet; `KineticAthleteCard` đọc từ snapshot cũ. Impact: user tưởng lưu thất bại.

**H10. "Xóa tài khoản" là giả** — `user_profile_remote_datasource.dart:121`
Docstring ghi xóa auth identity nhưng chỉ gọi RPC `delete_user_account` (không có migration .sql trong repo). User vẫn login lại được bằng email/pass cũ.

**H11. Lỗi xóa remote bị nuốt, UI vẫn báo thành công** — `user_profile_repository_impl.dart:112`
try/catch chỉ `debugPrint`; settings hiện "đã xóa thành công" dù server chưa xóa gì.

**H12. Đăng xuất không hủy notification đã schedule** — `profile_screen.dart:657`
Nhắc tập/check-in của user cũ vẫn nổ trên màn hình login — rò rỉ nội dung cá nhân.

**H13. Gạt công tắc noti ở Settings xóa sạch setting chi tiết** — `settings_screen.dart:330`
`_setNotificationsEnabled` ghi đè giờ nhắc 08:00/20:00 hardcode + mọi category = master.

**H14. Race condition đơn vị lúc mở form profile (imperial)** — `profile_setup_screen.dart:39`
`initState` đọc FutureProvider chưa resolve → luôn default metric; controller init kg nhưng UI hiện "lb" → có thể lưu 70kg thành ~31.8kg.

**H15. Số liệu quãng đường không nhất quán giữa các tab** — `workout_providers.dart:341-357` + `kinetic_recent_activity_card.dart:134`
Hai chỗ cộng `distanceKm` thô, các chỗ khác dùng `validDistanceKm ?? distanceKm`. Impact: Home hiện 5.2km, History hiện 4.8km cùng một buổi.

**H16. User imperial thấy số km gắn nhãn mile** — `home_screen.dart:131-134`
`_formatMetric(value,'mi')` không convert (`goalProgressProvider` thì có `kmToMi`). Impact: "12.5 / 20.0 MI" thực chất là km.

**H17. Ngưỡng Recovery cứng, sai ở view Năm** — `kinetic_recovery_guidance_card.dart:31`
`totalKm >= 30` áp cho mọi period → xem theo năm ai cũng kẹt ở "cường độ cao".
